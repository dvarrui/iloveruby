# Dibujitos

Hacer un programa que haga lo siguiente:

1. Dibujar por pantalla los siguientes patrones para un número N leído por teclado.

Por ejemplo, para N = 5:

```
*****
****
***
**
*

*****
*   *
*   *
*   *
*****

* * *
 * *
* * *
 * *
* * *

  *
 ***
*****
```
