
# Taylor

Enlaces de interés:

* Web site: https://taylormadetech.dev/
* Repo: https://github.com/HellRok/Taylor

# Instalación

* Descargar el zip (https://taylormadetech.dev/)
* Descomprimir y usar el comando `taylor`
* `taylor new hello`, para crear el proyecto "hello".
* Para ejecutar el juego.
    * `taylor hello/game.rb`
    * `cd hello && taylor`
